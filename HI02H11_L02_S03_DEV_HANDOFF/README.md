## The three things that will bite you

**1 · The deck changed, and PowerPoint hides it.**
The SME **deleted page 15** (the «मेरे ___ में दर्द है।» → पैर sentence) and moved page 17 ahead of
page 14. PowerPoint keeps the old `slideN.xml` names and only rewrites the order list, so reading
the .pptx in file order reports the **old** flow. `_SME_RECOMMENDATIONS.md` is already in the real
order. Position 15 carries **two** recommendations in one notes field — see the warning at the top
of that file.

**2 · The hint ladder changes shape: 2 rungs → 3.**
Hint 1 clarifies, Hint 2 compares (and its highlights **stay**), Hint 3 reveals and locks — and the
child still has to perform the action themselves. Nothing auto-completes. See §1 of the change
request. This is most of the engine work.

**3 · Never hand-edit the built HTML or the shared engine.**
`card.json` is generated by the builder. Per-game engine changes go in `engine_local/` and are
injected by `inject_train.py`, which is idempotent. `4_ENGINE/` is a copy of that folder — it is not
wired to anything here, it is for reading.

## Running it

```bash
cd 3_CURRENT_BUILD
python -m http.server 8000
```

Then open `http://127.0.0.1:8000/HI02H11_L02_S03.html`. Serve it over http — opening the file
directly blocks the audio and asset loads.

Two 404s (`pic_kaam.png`, `pic_naak.png`) appear on load. They are preload tags baked into the
shared engine's `<head>` pointing at an old demo lesson, they affect every game on this engine line,
and they are being fixed separately. They are not this lesson's assets.
